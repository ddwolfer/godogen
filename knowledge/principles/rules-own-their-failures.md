# 玩家的失敗要出自玩家的選擇,不是規則的鍋

當量測顯示「所有策略都在做蠢事」,先懷疑規則,不要先懷疑策略。

## 規則

- **規則拒絕玩家操作時必須有回饋**(紅閃、音效、訊息)。靜默吞掉操作會讓玩家把鍋算到錯的地方 —— 他回報出來的 bug 也會指向錯的系統。
- **舊機制退場時要巡檢它的衍生規則。** 主機制死了,依附它的限制常常還活著。
- **代理量測的異常統計是規則級 bug 的煙霧警報。** 「連謹慎策略都丟 97% 部隊」這種數字比單場 replay 更早暴露問題。
- 見 [[disaggregate-your-stats]]:異常統計要先拆開才知道是誰的。

## 案例

**拋棄全軍(深坑公會 2.0)**

撤離規則是「指揮官上船 = run 立刻結束」,導致連謹慎代理每趟都拋棄 2.9/3 支部隊 —— 指揮官先走,全軍在碼頭排隊到一半被硬生生截斷。

**玩家沒有選擇拋棄,是規則替他拋棄的。**

修正:指揮官上船後戰鬥繼續,全員撤出或戰死才結束,並加出口磁吸自動排隊上船。

**隱形牆**

佈署區限制 `x <= 11` 是搜打撤時代的遺物,把高地與城堡東側整片鎖在牆外。主機制早就退場了,這條限制還活著。

玩家右鍵被**靜默吞掉**,只能腦補「是不是模型擋住點擊」——(實際上點擊判定是平面射線,模型永遠不參與)。錯誤的心智模型直接來自缺少的回饋。
